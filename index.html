Integrasi Cloud Firebase

Hubungkan basis data Cloud Firestore dan Firebase Auth

Konfigurasi Proyek Firebase

Masukkan parameter konfigurasi web app dari Firebase Console > Project Settings > General > Your Apps.

Panduan Singkat Firebase

  1. Buka console.firebase.google.com.
  2. Buat proyek baru atau pilih proyek yang sudah ada.
  3. Aktifkan Cloud Firestore dalam mode test mode atau atur rules baca/tulis.
  4. Tambahkan web app ("</>") untuk mendapatkan config keys di atas.
  5. Salin nilai ke form di sebelah kiri dan klik Simpan.
